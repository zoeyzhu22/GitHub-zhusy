# Guide: Create your first GitHub repository
## Prerequisites
1. A valid GitHub account (registered and logged in)
2. Internet access
3. A web browser (Chrome, Edge, Firefox etc.)

## Steps
1. Go to https://github.com and sign in to your account.
2. Click the "+" icon at the top-right corner, then select "New repository".
3. Type a repository name (no space), choose Public or Private. Check "Add a README file".
4. Click the green "Create repository" button.
5. Open the README file and click the pencil icon to edit your content.

## Result Check
✅ Check 1: You can see your repository name on your GitHub profile page.
✅ Check 2: The README.md file exists and you can edit it.
✅ Check 3: The repository page loads without error.
